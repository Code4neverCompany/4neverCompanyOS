Export

Druck (Karten, Briefbogen):
  • Template öffnen → Strg+P → „Als PDF speichern“.
  • Ränder auf Keine, Option Hintergrundgrafiken aktivieren.
  • Karten enthalten 3 mm Beschnitt (Seitenformat 61×91 bzw. 91×61 mm); Schnittmarken setzt die Druckerei auf das Endformat 55×85 mm.
Pixel-Banner (LinkedIn, YouTube, GitHub, Instagram, Slides):
  • Template in Chrome/Edge öffnen → F12 → im Elements-Tab das <div class="canvas"> selektieren.
  • Strg+Shift+P → „Capture node screenshot“ → pixelgenaues PNG in Zielgröße.
  • Alternativ: Device-Toolbar auf die Canvas-Größe stellen und „Capture screenshot“. Beim YouTube-Banner vorher die Klasse guides entfernen.
E-Mail-Signatur: im Browser markieren, kopieren, in Outlook/Gmail-Signaturfeld einfügen (Anleitung im Datei-Kommentar).
